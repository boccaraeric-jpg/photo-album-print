ComClic

Commentez vos photos, sauvegardez ou partagez-les

On vous a envoyé un album ?

Un fichier .comclic contient un album photo entier — photos en pleine qualité, commentaires, lieux et dates. Il s'ouvre uniquement avec l'app ComClic.

Demander l'accès à l'app

ComClic est en phase de test privé. Écrivez-nous : vous recevrez une invitation TestFlight pour l'installer sur votre iPhone.

Ouvrir l'album une fois l'app installée

  1. Ouvrez le message (Mail, WhatsApp, AirDrop…) contenant le fichier .comclic.
  2. Touchez le fichier, puis Partager → ComClic.
  3. Choisissez le dossier de destination : l'album se reconstruit à l'identique.

Received a ComClic album?

A .comclic file holds a whole photo album — full-quality photos, captions, places and dates. It only opens with the ComClic app.

Request access

ComClic is in private testing. Email us and you'll get a TestFlight invitation. Once installed: tap the file → Share → ComClic.
